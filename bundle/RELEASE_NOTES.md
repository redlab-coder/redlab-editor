# RedLab Editor · Pacote completo 1.0.2

Esta versão inclui o Bottons Editor 1.2.3, com o quadrado centralizado ao lado dos redondos e alinhamento vertical das colunas nas folhas mistas. Polaroid e Medidas mantêm as mesmas versões.

Um único download para instalar suas ferramentas de impressão. Os três editores vêm selecionados; você pode escolher apenas os que precisa.

| Ferramenta incluída | Para que serve |
| --- | --- |
| Bottons Editor 1.2.3 | Modelos individuais e montagem de folhas |
| Polaroid Editor 1.2.1 | Enquadramento e conferência de polaroids |
| Medidas Editor 1.1.1 | Fotos em medidas personalizadas |

- Windows 10 e 11 de 64 bits, instalação por usuário, sem administrador.
- Instalação offline depois do download, com atalhos na pasta **RedLab Editor** do menu Iniciar.
- Atalhos na área de trabalho opcionais; nenhuma ferramenta abre automaticamente ao terminar.
- Instalações existentes são reutilizadas; uma versão mais recente é preservada.
- Cada editor mantém suas próprias atualizações e desinstalação.
- O resultado informa falhas por ferramenta e continua a instalação das demais. Não há reversão automática das instalações concluídas.

Salve o trabalho e encerre os editores escolhidos antes de instalar. O pacote não cria um quarto aplicativo. Para remover uma ferramenta, use **Aplicativos instalados** nas configurações do Windows.

`contents.json` identifica as versões e os instaladores incluídos. `SHA256SUMS.txt` permite conferir o download do pacote. A edição e as funções de impressão permanecem as mesmas dos instaladores individuais; a validação física do Medidas Editor na Noritsu continua pendente.
