# Contribuir

Ao abrir uma issue, informe o aplicativo, a versão e os passos para reproduzir. Use imagens de teste sem dados pessoais. Sugestões devem explicar o efeito no fluxo de produção.

Para alterações de código, consulte [desenvolvimento](docs/development.md) e o guia do aplicativo. Preserve medidas, gabaritos e contratos de exportação; documente mudanças de comportamento e execute os testes pertinentes. Cada aplicativo tem seu próprio ciclo de publicação.
