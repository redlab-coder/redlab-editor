# Publicação

Produto: `medidas-editor`. Versão atual: **1.1.0**. Tag: `medidas-v1.1.0`.

O workflow `medidas.yml` valida o motor, API, projetos, fila, maior formato, memória, executável, interface e instalador no Windows. A publicação usa os mesmos arquivos aprovados pelos testes e avança somente `updates/medidas-editor.json`.

Artefatos: `MedidasEditor-Setup-1.1.0.exe`, `MedidasEditor-Portable.exe`, `update.json` e `SHA256SUMS.txt`. O produto tem AppId, mutexes e pastas próprios. Instalar ou atualizar Medidas Editor não substitui Bottons Editor ou Polaroid Editor.
