# Imagens de apresentação

Banners e ícones são vetores próprios, derivados da família visual RedLab com paleta quente. `workspace.png` mostra a interface real; `contain.png` demonstra branco interno e externo. As imagens de demonstração são sintéticas e não contêm fotos de clientes.

`tests/browser_check.py` gera as capturas em uma instância isolada do aplicativo. O exemplo imprimível pode ser reproduzido com `scripts/example.py`.
