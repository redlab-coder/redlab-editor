# Canais de atualização

Cada arquivo JSON identifica um aplicativo e aponta para seu instalador publicado e validado.

- `bottons-editor.json`: somente Bottons Editor.
- `polaroid-editor.json`: somente Polaroid Editor.
- `medidas-editor.json`: somente Medidas Editor.

O manifesto é publicado automaticamente depois dos testes e do envio completo da release. Os canais não compartilham versões. Não edite hashes nem reaproveite uma versão para outro binário.
